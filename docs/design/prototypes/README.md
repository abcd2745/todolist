#### ✅ 注册页面 (`register.html`)

### 2. 核心功能模块

#### ✅ 主页/四象限视图 (`home.html`)

**路由**: `/home` 或 `/`

**功能**:
- 📊 四象限任务分类展示（2x2网格）
- 🎮 游戏化信息显示（XP、等级、连击）
- 📝 任务卡片（标题、截止日期、难度、XP）
- ✅ 任务完成交互
- ➕ 任务创建表单（弹窗）
- 🎬 动画效果（完成、XP飞入）

**设计要点**:
- 四象限差异化配色
  - Q1 (紧急且重要): 红色系
  - Q2 (重要不紧急): 蓝色系
  - Q3 (紧急不重要): 黄色系
  - Q4 (不紧急不重要): 绿色系
- 响应式布局
  - 桌面: 2x2网格
  - 平板/移动: 垂直堆叠
- 任务卡片悬停动画
- 实时XP计算预览

## 🎬 交互流程

### 任务完成流程

```
用户点击"完成任务"
    ↓
任务卡片动画（缩小+淡出）
    ↓
XP飞入动画
    ↓
XP更新动画
    ↓
（可选）升级动画
    ↓
（可选）成就解锁通知
```

### 创建任务流程

```
用户点击"+ 添加任务"
    ↓
弹出任务创建表单
    ↓
填写任务信息
    ↓
实时计算XP预览
    ↓
提交创建
    ↓
任务卡片出现
```

## 🎨 设计系统

### 颜色系统

```
主题色：
- 主色: #667eea (紫蓝渐变起点)
- 辅色: #764ba2 (紫蓝渐变终点)

四象限配色：
- Q1 (紧急且重要): #ef4444 (红)
- Q2 (重要不紧急): #3b82f6 (蓝)
- Q3 (紧急不重要): #f59e0b (黄)
- Q4 (不紧急不重要): #10b981 (绿)

功能性颜色：
- 成功: #10b981
- 警告: #f59e0b
- 危险: #ef4444
- 信息: #3b82f6
```

### 字体系统

```
主字体: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto
标题: 32px / 24px / 20px / 18px
正文: 14px / 12px
```

### 间距系统

```
容器间距: 20px
卡片内边距: 24px / 32px
元素间距: 8px / 12px / 16px / 24px
圆角: 8px / 12px / 16px / 24px
```

## 📱 响应式断点

```
桌面端: ≥1024px
  - 四象限: 2x2网格布局

平板端: 640px - 1023px
  - 四象限: 垂直堆叠

移动端: <640px
  - 简化导航
  - 增大触摸目标
  - 垂直堆叠
```

## 🔍 如何查看原型

### 本地查看

在浏览器中直接打开HTML文件：

```bash
# 进入原型目录
cd docs/design/prototypes

# 使用浏览器打开
open login.html        # macOS
xdg-open login.html    # Linux
start login.html       # Windows
```

### 推荐查看顺序

1. **登录页面** (`login.html`) → 体验登录流程
2. **主页** (`home.html`) → 查看四象限布局和任务管理
3. **任务详情** (`task-detail.html`) → 了解任务完整信息
4. **数据分析** (`analytics.html`) → 查看数据可视化
5. **成就殿堂** (`achievements.html`) → 浏览游戏化成就
6. **注册页面** (`register.html`) → 体验注册流程
