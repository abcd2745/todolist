**核心原则**: 理解我、帮助我、不评判我

**示例对比**:
- ❌ "你的连击已中断" → ✅ "欢迎回来！新连击从1开始"
- ❌ "你落后了15%" → ✅ "这周确实很忙，我帮你调整计划"

## 🎨 核心设计亮点

### 1. 四象限差异化设计

**设计思路**:
- 使用不同颜色区分四象限（红、蓝、黄、绿）
- 每个象限有独特的图标和命名
- 游戏化命名（主线任务、成长区域、村庄委托、休闲时光）

**用户体验**:
- 快速识别任务优先级
- 视觉上引导用户关注重要任务
- 降低认知负担

---

### 2. 游戏化动画系统

**动画设计**:
1. **任务完成动画**: XP 飞入 + 数字跳动
2. **等级提升动画**: 全屏庆祝 + 粒子特效
3. **成就解锁动画**: Toast 通知 + 图标旋转

**技术实现**:
- Vue Transition + CSS Animation
- Framer Motion (或 @vueuse/motion)
- GPU 加速（transform）

---

### 3. 数据可视化设计

**图表类型**:
- XP 趋势图（折线图）
- 四象限分布（饼图）
- 属性雷达图（雷达图）
- 成就进度（进度条）

**数据呈现原则**:
- 强调"发现"而非"问题"
- 提供可操作建议
- 支持用户反思
