🚀 极简开发环境教程

单数据库 + Schema隔离 + 按需清理

📖 方案介绍

架构设计

┌─────────────────────────────────────────┐ │ 单个PostgreSQL容器 (端口5432) │ │ │ │ ├── schema: public (系统表) │ │ ├── schema: agent_1 (Agent 1) │ │ ├── schema: agent_2 (Agent 2) │ │ └── schema: agent_N (Agent N) │ └─────────────────────────────────────────┘ 创建：./scripts/agent-env.sh agent_X create 清理：./scripts/agent-env.sh agent_X clean

✅ 核心优势

  • 极简：只需1个数据库容器
  • 无冲突：固定端口5432
  • 高效：Schema天然隔离
  • 易清理：删除Schema即可

🎯 适用场景

  • 多Agent并行开发
  • 团队协作开发
  • CI/CD自动化测试
  • 本地开发测试

🚀 快速开始

启动数据库（一次性）

所有Agent共享同一个数据库容器

docker-compose up -d
正在启动数据库容器... ✅ 数据库容器启动成功 ✅ 端口映射: localhost:5432 ✅ 数据库: todolist ✅ 用户: dev

创建Agent环境

为每个Agent创建独立的Schema

./scripts/agent-env.sh agent_1 create
======================================== 🚀 创建Agent环境: agent_1 ======================================== 📝 创建Schema: agent_1 ✅ Agent环境就绪！ 📊 Schema: agent_1 🔗 连接信息： Host: localhost:5432 Database: todolist User: dev Schema: agent_1

开始开发

连接数据库并切换到专属Schema

docker exec -it todolist-db psql -U dev -d todolist
psql (15.2) Type "help" for help. todolist=# _

切换到专属Schema：

SET search_path TO agent_1;

创建表和测试数据

-- 创建用户表 CREATE TABLE users ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), username VARCHAR(50) UNIQUE NOT NULL, email VARCHAR(100) UNIQUE NOT NULL, created_at TIMESTAMP DEFAULT NOW() ); -- 插入测试数据 INSERT INTO users (username, email) VALUES ('alice', 'alice@example.com'); -- 查询 SELECT * FROM users;

清理环境

测试完成后清理Schema（删除所有表和数据）

./scripts/agent-env.sh agent_1 clean
======================================== 🧹 清理Agent环境: agent_1 ======================================== 确认删除Schema 'agent_1'？(y/N): y ✅ Schema已删除

❓ 常见问题

Q1: Schema之间会互相影响吗？

不会。Schema是完全隔离的，每个Schema有独立的表、数据、权限。

Q2: 如何查看所有Schema？

docker exec -it todolist-db psql -U dev -d todolist -c "\dn"

Q3: 如何在应用中指定Schema？

# 方式1: 环境变量 export DB_SCHEMA=agent_1 # 方式2: 连接字符串 postgresql://dev:dev_password@localhost:5432/todolist?currentSchema=agent_1 # 方式3: SQL命令 SET search_path TO agent_1;

Q4: 清理Schema会影响其他Agent吗？

不会。清理agent_1的Schema只会删除agent_1的数据，其他Schema完全不受影响。

💡 实用技巧

批量清理所有测试Schema

# 清理所有agent_*开头的Schema for schema in $(docker exec -i todolist-db psql -U dev -d todolist -t -c \ "SELECT schema_name FROM information_schema.schemata WHERE schema_name LIKE 'agent_%';"); do echo "清理: $schema" docker exec -i todolist-db psql -U dev -d todolist -c "DROP SCHEMA IF EXISTS $schema CASCADE;" done

查看Schema大小

SELECT schemaname, pg_size_pretty(SUM(pg_total_relation_size(schemaname || '.' || tablename))::bigint) AS size FROM pg_tables WHERE schemaname NOT IN ('pg_catalog', 'information_schema') GROUP BY schemaname;

重置Schema（快速清理+重建）

./scripts/agent-env.sh agent_1 reset
