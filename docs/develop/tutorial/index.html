🚀 极简开发环境教程

单数据库 + Schema隔离 + 按需清理

📖 教程概述

🎯 方案核心

一个数据库，多个Schema，按需清理

  • 启动1个PostgreSQL容器（端口固定5432）
  • 每个Agent使用独立的Schema隔离数据
  • 测试完成后删除Schema即可重置环境

💡 为什么选择这个方案？

极简 只需1个容器，固定端口
无冲突 Schema天然隔离，无需协调
高效 共享资源，节省内存
易清理 删除Schema即可重置

🏗️ 架构设计

┌─────────────────────────────────────────┐
│     单个PostgreSQL容器 (端口5432)       │
│                                         │
│  ├── schema: public    (系统表)        │
│  ├── schema: agent_1   (Agent 1)       │
│  ├── schema: agent_2   (Agent 2)       │
│  └── schema: agent_N   (Agent N)       │
└─────────────────────────────────────────┘

创建：./scripts/agent-env.sh agent_X create
清理：./scripts/agent-env.sh agent_X clean

💼 适用场景

👥 多Agent并行开发

多个Agent同时工作，各自使用独立的Schema，互不干扰

🏢 团队协作

团队成员各自使用专属Schema，共享数据库实例

🤖 CI/CD测试

自动化测试创建独立Schema，测试完成后自动清理
