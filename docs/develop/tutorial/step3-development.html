🔌 数据库连接

连接参数详解：

# 连接字符串格式 postgresql://用户名:密码@主机:端口/数据库名 # 实际示例 postgresql://dev:dev_password@localhost:5432/todolist
  • 用户名：dev
  • 密码：dev_password
  • 主机：localhost（本机）
  • 端口：5432
  • 数据库：todolist

💻 应用集成

如何在应用代码中指定Schema？

方式1：环境变量（推荐）

# .env文件 DATABASE_URL=postgresql://dev:dev_password@localhost:5432/todolist DB_SCHEMA=agent_1

方式2：连接字符串参数

# 在连接字符串中指定Schema postgresql://dev:dev_password@localhost:5432/todolist?currentSchema=agent_1

方式3：SQL SET命令

# 每次连接后执行 SET search_path TO agent_1;

🛠️ SQLAlchemy集成示例

# Python代码示例 import os from sqlalchemy import create_engine, event from sqlalchemy.orm import sessionmaker DATABASE_URL = os.getenv("DATABASE_URL") DB_SCHEMA = os.getenv("DB_SCHEMA", "public") engine = create_engine(DATABASE_URL) # 自动切换Schema @event.listens_for(engine, "begin") def do_begin(conn): conn.exec_driver_sql(f"SET search_path TO {DB_SCHEMA}, public") SessionLocal = sessionmaker(bind=engine)

🔧 实际操作

1. 连接数据库

docker exec -it todolist-db psql -U dev -d todolist
psql (15.2) Type "help" for help. todolist=#

2. 切换到Agent Schema

-- 切换Schema SET search_path TO agent_1; -- 验证 SHOW search_path;
search_path ------------- agent_1 (1 row)

3. 创建测试表

-- 创建用户表 CREATE TABLE users ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), username VARCHAR(50) UNIQUE NOT NULL, email VARCHAR(100) UNIQUE NOT NULL, password_hash VARCHAR(255) NOT NULL, xp INT DEFAULT 0, level INT DEFAULT 1, streak_days INT DEFAULT 0, created_at TIMESTAMP DEFAULT NOW() ); -- 创建任务表 CREATE TABLE tasks ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), user_id UUID REFERENCES users(id), title VARCHAR(200) NOT NULL, description TEXT, quadrant INT CHECK (quadrant IN (1, 2, 3, 4)), status VARCHAR(20) DEFAULT 'pending', difficulty INT CHECK (difficulty BETWEEN 1 AND 5), created_at TIMESTAMP DEFAULT NOW() );

4. 插入测试数据

-- 插入用户 INSERT INTO users (username, email, password_hash) VALUES ('alice', 'alice@example.com', 'hash1'), ('bob', 'bob@example.com', 'hash2'); -- 插入任务 INSERT INTO tasks (user_id, title, quadrant, difficulty) VALUES ((SELECT id FROM users WHERE username = 'alice'), '学习Docker', 2, 3), ((SELECT id FROM users WHERE username = 'alice'), '完成项目', 1, 5);

5. 查询验证

-- 查询用户 SELECT * FROM users; -- 查询任务 SELECT t.title, u.username, t.quadrant, t.status FROM tasks t JOIN users u ON t.user_id = u.id;
title | username | quadrant | status ---------------+----------+----------+--------- 学习Docker | alice | 2 | pending 完成项目 | alice | 1 | pending (2 rows)

❓ 常见问题

Q: 如何导出数据？

# 导出Schema结构 docker exec todolist-db pg_dump -U dev -n agent_1 --schema-only todolist > schema.sql # 导出数据 docker exec todolist-db pg_dump -U dev -n agent_1 --data-only todolist > data.sql # 导出全部 docker exec todolist-db pg_dump -U dev -n agent_1 todolist > backup.sql

Q: 如何导入数据？

# 导入SQL文件 cat backup.sql | docker exec -i todolist-db psql -U dev -d todolist

Q: 如何快速查看Schema大小？

SELECT schemaname, pg_size_pretty(SUM(pg_total_relation_size(schemaname || '.' || tablename))::bigint) AS size FROM pg_tables WHERE schemaname = 'agent_1' GROUP BY schemaname;
