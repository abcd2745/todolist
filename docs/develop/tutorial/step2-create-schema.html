📖 理论说明

🗄️ PostgreSQL Schema

什么是Schema？

Schema是PostgreSQL中的命名空间，类似于文件夹的概念。每个Schema可以包含表、视图、索引、函数等数据库对象。

数据库 (Database): todolist │ ├── Schema: public (默认，系统表) │ ├── users表 │ └── tasks表 │ ├── Schema: agent_1 (Agent 1专属) │ ├── users表 │ └── tasks表 │ └── Schema: agent_2 (Agent 2专属) ├── users表 └── tasks表

🔒 Schema隔离原理

为什么Schema可以隔离数据？

  • 命名空间隔离：不同Schema中的表可以同名
  • 权限隔离：可以控制用户对Schema的访问权限
  • 数据隔离：每个Schema的数据完全独立

💡 关键优势

相比创建多个数据库，Schema更轻量级，共享连接池和系统资源，性能更高。

🎯 search_path机制

如何指定当前Schema？

PostgreSQL使用search_path参数来确定查找表的顺序。

-- 设置当前Schema SET search_path TO agent_1; -- 创建表（自动创建在agent_1 schema） CREATE TABLE users (...); -- 查询表（自动从agent_1 schema查找） SELECT * FROM users;

🔧 实际操作

1. 查看脚本内容

#!/bin/bash # scripts/agent-env.sh AGENT_ID=${1:-agent_1} ACTION=${2:-create} # 创建Schema docker exec -i todolist-db psql -U dev -d todolist <

📋 脚本详解

  • AGENT_ID=${1:-agent_1}
    参数化Agent ID，默认为agent_1
  • CREATE SCHEMA IF NOT EXISTS
    创建Schema（如果不存在）
  • GRANT ALL PRIVILEGES
    授予所有权限给dev用户

2. 创建Agent环境

./scripts/agent-env.sh agent_1 create
======================================== 🚀 创建Agent环境: agent_1 ======================================== ✅ Docker运行正常 📝 创建Schema: agent_1 ✅ Agent环境就绪！ 📊 Schema: agent_1 🔗 连接信息： Host: localhost:5432 Database: todolist User: dev Password: dev_password Schema: agent_1

3. 验证Schema创建

docker exec -it todolist-db psql -U dev -d todolist -c "\dn"
Name | Owner --------------------+------- agent_1 | dev public | dev (2 rows)

4. 创建多个Agent环境

# Agent 2 ./scripts/agent-env.sh agent_2 create # Agent 3 ./scripts/agent-env.sh agent_3 create # 查看所有Schema docker exec -it todolist-db psql -U dev -d todolist -c "\dn"
Name | Owner --------------------+------- agent_1 | dev agent_2 | dev agent_3 | dev public | dev (4 rows)

💡 最佳实践

Schema命名规范

  • 开发环境：agent_{id}（如 agent_alice, agent_bob）
  • 测试环境：test_{id}（如 test_unit, test_integration）
  • CI/CD环境：ci_{build_id}（如 ci_123, ci_456）

权限管理建议

  • 开发环境：使用GRANT ALL PRIVILEGES简化管理
  • 生产环境：遵循最小权限原则，只授予必要权限
  • 定期审计：检查Schema使用情况和权限分配

❓ 常见问题

Q: Schema名称有限制吗？

A: Schema名称必须以字母开头，长度不超过63个字符，推荐使用小写字母、数字和下划线。

Q: 如何在SQL中指定Schema？

-- 方式1: SET search_path SET search_path TO agent_1; -- 方式2: 完整限定名 SELECT * FROM agent_1.users; -- 方式3: 连接字符串参数 psql "postgresql://dev:dev_password@localhost:5432/todolist?options=-c%20search_path%3Dagent_1"

Q: 如何查看Schema中的表？

-- 切换到Schema SET search_path TO agent_1; -- 查看所有表 \dt -- 或使用SQL SELECT tablename FROM pg_tables WHERE schemaname = 'agent_1';
