# Docs 目录结构说明

## 目录结构

```
docs/
├── progress.md                              # 📊 动态项目进度（每次完成任务后更新）
├── agent_team_guide.md                      # 🤖 Agent Team 模式详细指南
├── team_organization_meeting_plan.md        # 👥 团队组织与会议计划
│
├── requirements/                            # 📋 业务需求分析
│   ├── requirements_document.md          # 产品需求文档（最终版本）
│   └── discussions/                         # 需求讨论过程记录
│       ├── discussion_record_01.md          # 需求讨论记录 1
│       └── discussion_record_02_longterm_learning.md  # 需求讨论记录 2
│
├── design/                                  # 🎨 设计方案
│   ├── plan_start_01.md                     # 初始设计方案（游戏化机制详解）
│   ├── frontend_tech_stack_comparison.md    # 前端技术栈选型对比分析报告
│   ├── ui_ux_design.md                      # UI/UX 设计规范
│   ├── ui_ux_prototype.md                   # UI/UX 设计原型展示文档
│   ├── api_specification.md                 # API 接口规范文档
│   ├── backend_technology_comparison.md     # 后端技术选型对比分析
│   ├── frontend_component_design.md         # 前端组件设计文档
│   ├── database_schema.md                   # 数据库 Schema 设计
│   └── prototypes/                          # 高保真 HTML 原型
│       ├── README.md                        # 原型目录说明文档
│       ├── login.html                       # 登录页面原型
│       ├── register.html                    # 注册页面原型
│       ├── home.html                        # 主页/四象限视图原型
│       ├── task-detail.html                 # 任务详情页原型
│       ├── analytics.html                   # 数据分析页原型
│       └── achievements.html                # 成就展示页原型
│
└── meetings/                                # 📝 会议记录（按阶段组织）
    └── resources/                           # 全局会议资源
        ├── templates/                       # 模板文件
        │   └── meeting_template.md          # 会议记录模板
        └── references/                      # 参考资料
            └── reference_links.md           # 参考链接汇总
```

---

## 目录职责说明

| 目录 | 职责 | 更新频率 |
|------|------|----------|
| `requirements/` | 业务需求分析相关文档 | 按需更新 |
| `requirements/discussions/` | 需求讨论过程记录 | 需求分析阶段更新 |
| `design/` | 设计方案和技术设计文档 | 按需更新 |
| `design/prototypes/` | 高保真HTML原型页面 | 设计阶段更新 |
| `meetings/` | 会议记录，按项目阶段组织 | 每次会议后更新 |
| `progress.md` | 项目进度、任务状态、阻塞风险 | 每次完成任务后更新 |
| `agent_team_guide.md` | Agent Team 模式详细指南 | 极少更新 |
| `team_organization_meeting_plan.md` | 团队角色职责和会议计划 | 极少更新 |
